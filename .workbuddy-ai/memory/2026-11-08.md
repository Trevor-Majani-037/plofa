`SHOT_*` event. They are different classes and AttackChain cannot see the brain. The

decision), and set-piece shots (corner/freekick/penalty) — nobody on the ball decided

1. **Perception — CORRECTED 2026-11-08 (user challenge; my first claim was wrong).**

4. **Stakes / choking** — `score_diff`+`minute` exist; stakes do not. Model as a shift

5. Lower cost: referee model (~20% of HA), opponent reputation memory, weather/pitch

# Foresight plan — `docs/FORESIGHT_PLAN_2026-11-08.md`

## The key discovery: instinct already exists, imagination does not

`consequence_decision.py` + `brains_trainer/critic_v5.json`:
- A **Q-critic is ON BY DEFAULT** (graduated 2026-09-20). `kind=value_critic`,
  `arch=[35,32,32,10]` (24 sensors + 11 position one-hot -> 10 Q-values), TD gamma=0.97.
- Applied as `logits = log(p) + 0.3 * advantage`, `advantage = q - p·q`
  (`ConsequenceEvaluator.correct_policy`). Blend 0.3; 0.5 over-corrects.
- **It is stale and blind**: `meta.sensor_schema = "v1_24d"`, dated 2026-09-20 — six weeks
  before goal vision. Every decision today is nudged by a critic that cannot see the goal.
- **It is starved**: input is 35 floats. It cannot see tokens, attention or the GRU state —
  it judges with less information than the brain it advises.

So: PLOFA has **instinct** (model-free Q) but no **imagination** (no transition model,
no `s' = f(s,a)`, no rollout anywhere).

## The ladder

- L0 fix the instinct: critic on v5 schema + fed the brain's latent. Days. Prerequisite.
  Gate: Q(SHOOT) > Q(SAFE_PASS) in an unpressured central clear chance (today reversed).
- L1 one-step imagination: `h' = f(h, intent, context)`, score `r + gamma*V(h')`, 10 intents.
  ~10 extra 32-d matmuls per decision — compute is not the constraint.
  Gate: must beat the `h' = h` baseline.
- L2 if L1 fails: the latent was trained to CHOOSE, not to PREDICT. Add an auxiliary
  next-state prediction loss (`action_loss + lambda*||g(h_{t+1}) - target||^2`) so the GRU
  becomes predictive. Trainer change, not architecture change. Budget for it.
- L3 2-ply with attention pruning: 10 intents x top-3 attended teammates = 30/ply.

## THE SEQUENCING CONSTRAINT

**Foresight multiplies your values.** With the current reward table (SHOOT 0.957 <
DRIBBLE 1.163), a foresighted brain will *deliberately* choose the dribble and be harder
to argue with. So: shot fix + reward geometry FIRST, then critic, then rollout.
Doing it in the wrong order produces a confident, articulate, wrong player.

## Tests (all cheap)

1. Transition accuracy vs `h' = h` baseline.
2. Counterfactual divergence: do greedy and 1-ply ever disagree, and which does it pick?
3. The football test: safe square pass (turnover under pressure) vs riskier ball that
   creates a chance. Instinct prefers the pass; foresight should prefer the through ball.

## What it still won't give

No deception (needs a model of another mind), no stakes, no commitment, no in-match learning.

### Commitment: decide at ball-release, not at arrival

## Fresh corpus, first real measurement (2026-11-12, resumed)

### Collection mechanics (learned the hard way)
- `collect()` saves ONLY after ALL matches finish (`prior + data` -> `_save_raw`), so a
  killed run loses everything.  A 12-match run died at a turn boundary and wrote nothing.
  **Chunk it**: 4 matches per invocation, each appends, each completes inside a turn.
- It APPENDS, so a repeat with the same `--seed` replays identical matches and duplicates
  the corpus. **Every chunk needs a fresh seed.**
- `--no-evolve` STILL runs the 2-match gate ([4/6]), ~12 min wasted. `--gate-matches 0`
  divides by zero. Use `tools/ops/collect_corpus.py` (collect + refit only).
- Real cost is ~6 min/match, not the "~20s" in the CLI help.
- Measured: 4 matches -> 3,146 samples (892/807/697/750 per match).

### `report()` cell count was summing squares
`n_cells = sum(len(v) for v in table.values() for v2 in v.values())` counts the BUCKET
dict once per intent, so it reports sum(k^2).  It claimed 105,839 filled cells from 3,146
samples — more cells than samples, which is how it was caught. Real count 2,628. Fixed to
`len(v2)`. This number is the plan's own "count the populated cells" gate, so it mattered.

## THE ROOT CAUSE: a shoot decision was credited 0.0, always (2026-11-12)

### What was found
`surrogate_collect._correlate_outcomes_causal` contains a documented branch: a policy
SHOOT intent makes the possession chain emit a ZERO-LENGTH marker carry (threat change
exactly 0.0) and the real shot is fired by the ATTACK chain, so a shoot decision must be
answered by looking FORWARD in the match timeline for the shot it caused.
The branch is guarded by `and timeline is not None`. **`surrogate_rebuild._run_matches`
passed no timeline.** The branch was dead code.

Consequence: every shoot decision was joined to the marker carry and credited exactly 0.0,
while the shot's xG — and any GOAL — was credited to nobody. `threat_reward.GOAL_VALUE`
is 1.0 and **no sample in 9,109 had a reward above 0.3841**.

Measured on the pre-fix corpus (9,109 samples):
- SHOOT: mean **+0.0009**, median 0.0, **36.5% exactly 0.0**, max +0.3503
- ALL samples: max +0.3841, mean **-0.00175** (negative), 0 samples >= 0.5
- `goal_value` in the reward manifest: 1.0 — a value nothing in the corpus could reach

So the surrogate could not express "shooting is worth it", and the GA faithfully learned
not to shoot. This is a THIRD route to the same collapse the plan documented, and it sits
BELOW the reward-key problem: fixing the bucket key cannot help if the shot's outcome was
never recorded.

### The fix
`_correlate_outcomes_causal(_CHAIN_CALLS, timeline=result.timeline)` — one argument.
`MatchResult.timeline` already existed. Verified on 1 match: SHOOT mean **+0.0101** (10x),
zeros **23.1%** (was 36.5%).
`tests/test_shoot_credit.py` (7 tests) pins the mechanism directly with a synthetic
timeline: a GOAL event IS credited GOAL_VALUE=1.0 to the shoot decision, another player's
goal is NOT claimed, a goal in a later minute is NOT claimed, one goal cannot be paid
twice — and a SOURCE assertion that `_run_matches` still passes `timeline=`, because the
bug was a missing argument and every mechanism test passes without the wiring.

### Consequence for the corpus
The 9,109 samples were collected through the broken call site, so their SHOOT rewards are
invalid (the non-SHOOT movers are unaffected — the timeline only changes how SHOOT is
answered). Quarantined as `brains_trainer/corpus_20261112_prefix_shootcredit.json`;
recollection started with the fix (seed 5001).
