# 2026-11-07

## Deep research audit of PLOFA (read-only)

Wrote `docs/RESEARCH_AUDIT_2026-11-07.md` — full-project audit: architecture, brain
lineage, measured football realism, test/repo health, prioritized recommendations.
No production file modified.

Key verified findings:

1. **Decision observability is severed in 3 places.** (a) `event_chain.py` stamps
   `metadata["active_brain"]` only on SHOT (l.2134) and CARRY (l.2289), never on PASS.
   (b) `exporter._timeline_json()` drops `metadata` — 0 of 227,332 events across 85
   match files carry `active_brain`. (c) `brain_observatory.py` is broken 5 ways:
   SyntaxError l.254 (`*: int`), SyntaxError l.431 (`?` placeholder), imports
   `collect_decisions` (missing), `auto_run_match` imports `write_trace` (missing),
   `--save-trace` writes `decisions: []` that nothing fills. 0 `*_brain_trace.json`
   exist on disk. Production degrades to a caught warning.
2. **No home advantage.** `is_home` threaded into `auto_team_style()` and unused.
   26/27: home 1.54 vs away 1.76 goals. The README's "home-goal inflation +24%" comes
   from `battlefield/run_plofa.py:73` style-slot offset (+5), not the engine.
3. **Season xG is not homogeneous.** MD1-4 xG/team 2.2-3.3, MD5-9 1.46-1.73, while
   shots and goals stay flat → xG model changed mid-season.
4. **xG per shot 0.119 vs conversion 0.107** → systematic over-rating of chance quality.
5. **`pytest tests/` collects 129 of 1,884 test functions** — `tests/test_brain_schema.py:225`
   raises SystemExit at import and aborts collection. No aggregate runner works.
6. **Coverage inversion:** shipped `situational_brain.py` has 1 test file (25 tests);
   the off-by-default `physics/` has 93.
7. **Dead weight:** 32/132 root modules orphaned; `value_model.py` imported only by
   orphaned `consequence_probe.py`; defensive situational `.npz` brains never wired
   (legacy `brains_def/ACTION.json` from 2026-09-10 still live).
8. **Repo bloat:** 217 MB of GPS CSVs tracked, `season_stats.json` (22 MB) whitelisted
   and committed per matchday → `.git` is 354 MB.

Monolith sizes: `event_chain.py` 11,036 lines with `PossessionChain.generate` = 2,586
lines in one function; `match_engine._simulate_minute` = 1,000 lines.

Repro note: `brain_observatory` was patched only in a temp copy
(`%TEMP%\plofa_obs\`) to get a live match + trace; repo copy untouched.
